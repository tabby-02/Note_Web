#  一、机器学习

# 1.基本概念

Samule定义的机器学习：赋予计算机在没有明确编程的情况下学习能力的研究领域

机器学习主要类型：

**监督学习**（学习输入x到输出y（正确标签））

:one:回归预测（在无数个可能输出数字中预测数值）

:two:分类算法（从一小部分可能的输出中预测一个类别）

**无监督学习**（仅包含输入x，没有输出标签y）

:one:聚类算法（将相似的数据点分组在一起）

:two:异常检测（用于检测异常）

:three:降维（将大数据集压缩成小得多的数据集）

# 2.线性回归模型（监督学习的回归预测）

| 符号含义                                    |
| ------------------------------------------- |
| x:输入变量/输入特征                         |
| y:输出变量/目标变量                         |
| m:样本数量                                  |
| (x,y):单一样本                              |
| (x<sup>(i)</sup>,y<sup>(i)</sup>):第i个样本 |
| y<sup>^</sup>:y-hat,y的预测值               |

$$
线性表示：y_{(w,b)}(x)=wx+b
$$

$$
代价函数/平方误差代价函数：J(w,b)=\frac{1}{2m}\sum_{i=1}^m(\hat{y}^{(i)}-y^{(i)})^2
$$

## 2）梯度下降算法

$$
赋值算法：\begin{cases}
w=w-\alpha\frac{\partial}{\partial w}J(w,b) \\
b=b-\alpha\frac{\partial}{\partial b}J(w,b)
\end{cases}\\
\alpha:学习率（0，1），控制下坡速度
$$

<img src="Snipaste_2025-09-10_14-51-35.png" style="zoom:33%;" />同步更新（求b的时候用的是**旧的w**）

### 线性回归模型的梯度下降算法

$$
\begin{cases}
w=w-\alpha\frac{1}{m}\sum_{i=1}^m(f_{w,b}(x^{(i)})-y^{(i)})x^{(i)} \\
b=b-\alpha\frac{1}{m}\sum_{i=1}^m(f_{w,b}(x^{(i)})-y^{(i)})
\end{cases}
$$

## 3)多特征多元线性回归

其中：\overrightarrow{x}=[x_1,x_2,x_3\cdots,x_n]\ \ \ \ \overrightarrow{w}=[w_1,w_2,w_3\cdots,w_n]

## 8）特征工程

利用对问题的知识或者直觉来设计新的特征，通常是通过转换或组合问题的原始的特征，以便更容易的使学习算法做出更准确的预测
$$
f_{\overrightarrow{w},b}(\overrightarrow{x})=w_1x_1+w_2x_2+b\\
当认为x_3更能决定f时，定义：x_3=x_1x_2\\
f_{\overrightarrow{w},b}(\overrightarrow{x})=w_1x_1+w_2x_2+w_3x_3+b
$$

## 9）多项式回归

使用多项式回归来拟合一些非线性数据集（注意要使用特征缩放，针对不同次幂）
$$
f_{\overrightarrow{w},b}(\overrightarrow{x})=w_1x+w_2x^2+b\\
f_{\overrightarrow{w},b}(\overrightarrow{x})=w_1x+w_2x^2+w_3x^3+b\\
f_{\overrightarrow{w},b}(\overrightarrow{x})=w_1x+w_2\sqrt{x}+b\\
$$

## 2）PyTorch

Facebook主导的研究型框架，动态计算图特性突出

### 自动微分系统?

PyTorch的**自动微分**工作原理：

1. 前向传播时记录运算图
2. 反向传播时自动计算梯度
3. 通过`.backward()`触发梯度计算

```python
import torch
import torch.nn as nn
import torch.optim as optim

class Net(nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        self.fc1 = nn.Linear(784, 64)
        self.fc2 = nn.Linear(64, 10)
    
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.softmax(self.fc2(x), dim=1)
        return x

model = Net()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters())
```

# 19.迁移学习

1）作用：允许你使用来自不同任务的数据来帮助你的应用

迁移学习的两个步骤：一个是下载一个神经网络，它在一个大数据集上已经预训练好了参数，并且它的输入类型与你的应用相同（图像、音频、文本），然后进一步训练或微调网络你自己的数据

方法1：只训练输出层的参数，其他层的参数直接使用和参照网络完全相同的值（适于小的训练集）

方法2：训练网络中的所有参数，但除了输出层的参数将使用在参照网络的值进行初始化（适于大的训练集）

2）**<u>*有监督预训练*</u>**：**首先在大数据集上训练**，**然后在较小的数据集上调整参数**

在第一步中，在一个非常大的数据集上训练神经网络，比如一百万张与任务不太相关的图像，然后第二步叫做微调，您使用从有监督预训练中初始化的参数，然后运行梯度下降进一步微调权重，以适应您可能有的手写数字识别的特定应用

3）为什么迁移学习会起作用

以图像为例子，因为你正在帮助它<u>学习检测图像中的通用特征</u>，找到边缘， 角落，曲线，基本的形状，这对许多其他计算机视觉任务都是有用的

如果数据集的**正例与负例的比例**严重偏离50/50，那么通常的**错误指标如准确率就不那么有效了**，因为**错误率最低的算法可能不是一个特别有用的预测**。（如果有一种罕见疾病人群中0.5%的患者患有这种疾病，那么，如果你写了一个程序，只说打印y等于0，这将实际具有99.5%的准确度或0.5%的错误，所以这个非常愚蠢的算法超过了你的学习算法）

在处理偏斜数据集时，通常使用一种**不同的误差指标**，而不是仅仅使用分类误差来确定您的学习算法的表现，一组常见的误差指标是**精确率和召回率**，特别是在评估学习算法的一个稀有类别的性能时，构建一个**混淆矩阵**会很有用，

# 补充、各网络类型详解

[1.**前馈神经网络（FNN）**](#1.神经网络层)

- **数据结构**：**向量**。输入数据被展平为一个固定长度的特征向量。
- **连接方式**：**层间全连接，信息单向流动（从输入到输出）**，无环。是最基础、最经典的神经网络架构。
- **核心思想**：每一层的神经元接收上一层的**所有**输出，进行加权求和、非线性变换，传递给下一层。
- **典型应用**：早期的图像分类、简单的非线性回归/分类问题。当输入是图像时，需要将像素矩阵“压平”成一维向量，这会破坏空间结构。
- **类比**：一个庞大的、多层级的**官僚体系**，每个官员（神经元）需要阅览所有下级（前一层所有神经元）的报告，整合后向上级汇报。

2.**反馈神经网络（FeedbackNN）**

- **说明**：这是一个**广义的、有时易混淆的类别**。它通常指网络中**信息可以反向或循环流动**的网络。
  - **狭义上**，常指 **Hopfield网络** 等具有循环连接用于联想记忆的早期模型。
  - **广义上**，**RNN 就是一类非常重要的反馈神经网络**，因为它的隐藏层之间存在循环连接。有时，任何带有“回路”的连接（不一定是时间序列）都可以归入此类。
- **核心思想**：网络输出或状态可以反馈回输入或中间层，形成动态系统，能够达到稳定状态或产生振荡等行为。
- **与RNN的关系**：**RNN是反馈神经网络在时序数据上最成功的特例和应用**。

[3.**图神经网络（GNN）**](#四、GNN图神经网络)

- **数据结构**：**图结构数据**。由**节点**、**边**和**全局信息**组成，关系复杂且不规则（非欧氏空间），如社交网络、分子结构、知识图谱。
- **连接方式**：基于图的拓扑结构进行**消息传递**。每个节点通过聚合其邻居节点的信息来更新自己的表示。
- **核心思想**：**关系归纳偏置**。特征学习和信息传播由图的连接关系决定，旨在捕捉节点间的依赖和交互。
- **典型应用**：社交网络用户推荐、药物分子性质预测、交通流量预测、反欺诈。
- **类比**：一个在**社交聚会中更新观点的人**。每个人（节点）通过与自己的朋友（邻居）交谈（消息传递），融合大家的意见，最终形成自己新的看法（节点表示）。

<img src="Snipaste_2025-12-01_16-04-13.png" style="zoom:50%;" />

[4.**循环神经网络（RNN）**](##6.RNN及变体)

- **数据结构**：**序列数据**。数据点之间有顺序依赖关系，如时间序列、文本句子、语音。
- **连接方式**：网络单元**不仅接收当前输入，还接收上一时刻的“隐藏状态”**，形成一种“循环”或“记忆”结构。
- **核心思想**：具有**内部记忆**，能够捕捉时间或顺序上的动态信息和长期依赖关系。
- **典型应用**：机器翻译、文本生成、股票预测、语音识别。基础RNN有梯度消失/爆炸问题，因此常用其变体**LSTM**（长短期记忆网络）和**GRU**。
- **类比**：一个**有记忆的剧本作家**。他写下一句台词时，不仅看当前的剧情提示（当前输入），还会回想之前所有已写下的剧情（隐藏状态），以保证故事连贯。

5.**卷积神经网络（CNN）**

- **数据结构**：**具有空间或网格结构的数据**，如图像（2D网格）、音频（1D序列）、视频（3D网格）。
- **连接方式**：使用**卷积核（过滤器）** 进行**局部连接**和**权值共享**。
- **核心思想**：**局部性**（一个像素只受周围像素影响）和**平移不变性**（一个模式无论在图像的哪个位置都适用同一个识别器）。通过卷积层自动提取从边缘到物体的层次化特征。
- **典型应用**：计算机视觉（图像分类、目标检测）、语音识别、部分自然语言处理（文本也可视为一维序列）。
- **类比**：一个使用特定模板（卷积核）的**巡查员**，他用这个模板在整片区域（图像）上逐块巡逻检查，寻找特定模式（如直角、圆形），且无论模式出现在哪里都用同一模板识别。

总结对比

| 网络类型   | 核心数据结构     | 连接/信息流动特点            | 核心能力           | 典型应用                     |
| :--------- | :--------------- | :--------------------------- | :----------------- | :--------------------------- |
| FNN        | 向量             | 全连接，前向无环             | 通用函数逼近       | 基础分类/回归                |
| FeedbackNN | 多样（向量序列） | 信息可反向或循环流动         | 动态系统、联想记忆 | 联想记忆（如Hopfield网）     |
| GNN        | 图（节点与边）   | 基于图拓扑的消息传递         | 建模关系与交互     | 社交网络、推荐系统、药物发现 |
| RNN        | 序列（文本等）   | 循环连接，具有内部状态       | 捕捉时序依赖       | 机器翻译、时间序列预测       |
| CNN        | 网格（图像等）   | 局部连接，权值共享，平移不变 | 提取空间局部特征   | 图像识别、计算机视觉         |

# 四、GNN图神经网络

GNN，即图神经网络，是一种用于处理图形数据的深度学习技术。([图神经网络（GNN）最简单全面原理与代码实现！ - 知乎](https://zhuanlan.zhihu.com/p/603486955))

## 1. 什么是图数据，在图神经网络中，图数据是以什么形式表示的

图数据是由**节点（Node）**和**边（Edge）**组成的数据，最简单的方式是使用邻接矩阵来表示图形结构，从而捕捉图形中的节点和边的相关性。假设图中的节点数为n，那么邻接矩阵就是一个n*n的矩阵，如果节点之间有关联，则在邻接矩阵中表示为1，无关联则为0。在图中，鲁班与其他英雄都没有关联，表现在邻接矩阵当中就是它所在的行与列为全零。

![img](https://pic3.zhimg.com/v2-2d64bf77a849403f37b531e032f97526_1440w.jpg)

**图数据的信息包含3个层面，分别是节点信息（V）、边信息（E）、图整体（U）信息**，它们通常是用向量来表示。而图神经网络就是通过学习数据从而得到3个层面向量的最优表示。

## 2. 对于图数据而言有怎样的任务

●*图层面的任务*（分类/回归）

例：分子是天然的图，原子是节点，化学键是边。现在要做一个分类，有一个苯环的分子分一类，两个苯环的分子分一类。**这是图分类任务**。

●*边层面的任务*（分类/回归）

例：UFO拳击赛上，首先通过语义分割把台上的人和环境分离开来。赛场上的人都是节点，现在要做一个预测，预测的是这些人之间的关系，是对抗关系，还是观众watch的关系，还是裁判watch的关系，**这是边分类任务。**

●*节点层面的任务*（分类/回归）

例：假设一个跆拳道俱乐部里有A、B两个教练，所有的会员都是节点。有一天A、B两个跆拳道教练决裂，那么各个学员是愿意和A在一个阵营还是愿意和B在一个阵营，**这是节点分类任务。**

## **3. 图神经网络是如何工作的**

![img](https://pic3.zhimg.com/v2-7bb8abbe1cb9d7365116abd5cabc3674_1440w.jpg)

GNN工作流程图

GNN是对图上的**所有属性进行的一个可以优化的变换**，它的输入是一个图，输出也是个图。它只对属性向量（即上文所述的***V、E、U\***）进行变换，但它**不会改变图的连接性**（即哪些点互相连接经过GNN后是不会变的）。在获取优化后的属性向量之后，再根据实际的任务，后接全连接神经网络，进行分类和回归。**大家可以把图神经网络看做是一个图数据的在三个维度的特征提取器。**

GNN对属性向量优化的方法叫做**消息传递机制。**比如最原始的GNN是SUM求和传递机制；到后面发展成[图卷积网络](https://zhida.zhihu.com/search?content_id=222240356&content_type=Article&match_order=1&q=图卷积网络&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NjQ2Mzk2NDYsInEiOiLlm77ljbfnp6_nvZHnu5wiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyMjIyNDAzNTYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.hiB8A5EU3gOnVu4CKKA5gef-kFFJoza_M4FkY-VsQNc&zhida_source=entity)（GCN）就考虑到了节点的度，度越大，权重越小，使用了加权的SUM；再到后面发展为[图注意力网络](https://zhida.zhihu.com/search?content_id=222240356&content_type=Article&match_order=1&q=图注意力网络&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NjQ2Mzk2NDYsInEiOiLlm77ms6jmhI_lipvnvZHnu5wiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyMjIyNDAzNTYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.fbSKeMOvxV61OqN0PI1gJgW00HT8l0ydWzeFrPESzzw&zhida_source=entity)GAT，在消息传递过程中引入了注意力机制；目前的SOTA模型研究也都专注在了消息传递机制的研究。见下图所示。

## 1.文本分类系统

文本分类(Text Classification)是自然语言处理(NLP)中最基础也是最重要的任务之一。它的目标是将给定的文本文档自动归类到一个或多个预定义的类别中。

一个完整的文本分类系统通常包含以下几个步骤：**<u>*文本预处理，特征提取，分类模型*</u>**

### 1）文本预处理

文本预处理是自然语言处理（NLP）中的基础且关键步骤，它将原始的**非结构化文本**数据转化为适合机器学习模型处理的**格式**。

文本预处理的三大核心环节：**文本清洗、分词和词性标注。**

1）**文本清洗**：净化原始文本数据

文本清洗是预处理的第一步，目的是去除文本中的**噪声数据**，提高后续处理的准确性。

2）**分词**（Tokenization）：将文本分解为基本单元

分词是将连续文本分割成**有意义的语言单元**（token）的过程，不同语言需要不同的分词方法。

3）**词性标注**：理解词语的语法角色

词性标注（Part-of-Speech Tagging）是为分词结果中的每个词语标注其**词性类别**的过程。

### 2）文本表示（特征提取）

#### 传统文本表示

文本表示是自然语言处理（NLP）中的基础任务，它将**非结构化的文本**数据**转化为计算机可以处理的数值形式**。

1）词袋模型（Bag of Words）

- 忽略词语顺序和语法，只关注词语是否出现
- 构建词汇表，统计每个词在文档中**出现的次数**
- 最终表示为一个高维稀疏向量

2）TF-IDF（Term Frequency-Inverse Document Frequency）

TF-IDF是对词袋模型的改进，考虑了词语在整个**语料库中的重要性**。降低常见词的影响，突出重要词。

- TF（词频）：`词在文档中出现的次数 / 文档总词数`
- IDF（逆文档频率）：`log(文档总数 / 包含该词的文档数)`
- TF-IDF = TF × IDF

3）N-gram 模型

N-gram 模型考虑了词语的顺序信息，通过连续n个词的组合来表示文本。捕捉**局部词序信息**，可以表示**短语和固定搭配**

- Unigram (1-gram)：单个词
- Bigram (2-gram)：两个连续词的组合
- Trigram (3-gram)：三个连续词的组合

## 4.关系抽取

### 1）关系抽取的核心要素

1. **实体识别**：首先需要识别文本中的命名实体
2. **关系分类**：然后判断这些实体之间存在什么类型的关系
3. **关系表示**：最后以结构化形式表示这些关系

2. 监督学习方法

## 6.RNN及变体

### 1）循环神经网络（RNN）

循环神经网络（RNN） 是一种**专门处理序列数据（如文本、语音、时间序列）的神经网络**。

与传统的前馈神经网络（FNN）不同，RNN 具有**"记忆"能力**，**能够保存之前步骤的信息**。

循环神经网络能够利用前一步的隐藏状态（Hidden State）来影响当前步骤的输出，从而捕捉序列中的时序依赖关系。

RNN 的核心在于**循环连接**（Recurrent Connection），即网络的输出不仅取决于当前输入，还取决于之前所有时间步的输入。这种结构使 RNN **能够处理任意长度的序列数据。**

**传统神经网络**：输入和输出是独立的（例如图像分类，单张图片之间无关联）。

一般来说，按**时间顺序**处理序列。（双向可以同时按时间顺序和逆序）

RNN 在每个时间步 t 执行以下计算：

1. 接收当前输入 xₜ 和前一时刻的隐藏状态 hₜ₋₁
2. 计算新的隐藏状态 hₜ = f(Wₕₕ·hₜ₋₁ + Wₓₕ·xₜ + b)
3. 产生输出 yₜ = g(Wₕᵧ·hₜ + c)

其中 f 和 g 通常是激活函数（如 tanh 或 softmax）。

### :yum:RNN 的优缺点（？）

**优点**：

- 能够处理变长序列
- 理论上可以记住任意长度的历史信息
- 参数共享（同一组权重用于所有时间步）

**缺点**：

- 梯度消失/爆炸问题（**难以学习长期依赖**）
- 计算效率较低（无法并行处理时间步）

### 2）长短期记忆网络（LSTM）

LSTM（Long Short-Term Memory）是 RNN 的一种改进架构，专门设计来解决标准 RNN 的**长期依赖问题**。

LSTM 引入了三个门控机制和一个记忆单元：

| 组件     | 功能               |
| :------- | :----------------- |
| 输入门   | 控制新信息的流入   |
| 遗忘门   | 决定丢弃哪些旧信息 |
| 输出门   | 控制输出的信息量   |
| 记忆单元 | 保存长期状态       |

**LSTM 如何解决长期依赖问题**

1. **选择性记忆**：遗忘门可以决定保留或丢弃特定信息
2. **梯度通路**：记忆单元提供了相对直接的梯度传播路径
3. **信息保护**：记忆内容不会被每个时间步的操作直接修改

### 3）门控循环单元（GRU）

GRU（Gated Recurrent Unit）是 LSTM 的简化版本，在保持相似性能的同时减少了参数数量。

GRU 合并了 LSTM 的某些组件：

| 组件     | 功能                   |
| :------- | :--------------------- |
| 更新门   | 决定保留多少旧信息     |
| 重置门   | 决定如何组合新旧信息   |
| 候选激活 | 基于重置门计算的新状态 |

### GRU vs LSTM

| 特性     | GRU          | LSTM             |
| :------- | :----------- | :--------------- |
| 参数数量 | 较少         | 较多             |
| 训练速度 | 更快         | 较慢             |
| 记忆单元 | 无           | 有               |
| 门控数量 | 2个          | 3个              |
| 性能     | 小数据集更好 | 大数据集可能更好 |

### 4）双向 RNN（Bi-RNN）

双向 RNN 通过同时考虑过去和未来的上下文信息，增强了序列建模能力。

**双向 RNN 架构**

Bi-RNN 包含**两个独立的 RNN 层**：

1. 前向层：按时间顺序处理序列
2. 反向层：按时间逆序处理序列

最终输出是这两个方向输出的组合（通常为拼接或求和）。

### 双向 LSTM/GRU

现代应用中，双向 RNN 通常使用 LSTM 或 GRU 作为基础单元

## 7.注意力机制

### 基本概念

注意力机制的核心思想是：**根据输入的不同部分对当前任务的重要性，动态分配不同的<u>*权重*</u>**。这种权重分配不是固定的，而是根据上下文动态计算的。

### 数学表达

注意力机制通常可以表示为：

```
Attention(Q, K, V) = softmax(QK^T/√d_k)V
```

其中：

- Q (Query)：当前需要计算输出的查询项
- K (Key)：用于与查询项匹配的键
- V (Value)：与键对应的实际值
- d_k：键的维度，用于缩放点积结果（d_k是缩放因子，防止点积过大导致梯度消失）

### 为什么需要注意力机制

1. **解决长距离依赖问题**：传统RNN难以捕捉远距离词语间的关系
2. **并行计算能力**：相比RNN的顺序处理，注意力可以并行计算
3. **可解释性**：注意力权重可以直观展示模型关注的重点

### 自注意力机制(Self-Attention)

自注意力是注意力机制的一种特殊形式，它允许输入序列中的每个元素都**与**序列中的**所有其他元素<u>*建立联系*</u>**。

#### 工作原理

1. 对输入序列中的每个元素，计算其与所有元素的相似度得分
2. 使用softmax函数**将这些相似度得分转换为权重**(0-1之间)
3. 用这些权重对对应的值进行加权求和，得到输出

#### 自注意力的优势

1. **<u>*全局上下文感知*</u>**：每个位置都能直接访问序列中所有位置的信息
2. **位置无关性**：不依赖序列顺序，适合处理各种结构化数据
3. **高效计算**：相比RNN的O(n)复杂度，自注意力可以并行计算

### 多头注意力(Multi-Head Attention)

多头注意力是自注意力的扩展，它将注意力机制并行执行多次，然后将结果拼接起来。

#### 结构组成

1. **多个注意力头**：通常使用8个或更多并行的注意力头
2. **线性变换层**：每个头有自己的Q、K、V变换矩阵
3. **拼接和输出**：将各头的输出拼接后通过线性层

## 8.Transformer 架构

Transformer 架构是一种**基于自注意力机制**的深度学习模型，旨在处理自然语言等顺序输入数据，适用于机器翻译、文本摘要等任务。然而，与 RNN 不同，Transformer 无需逐步处理序列，而是**可以一次性并行处理整个输入**。

Transformer 的核心思想是完全依赖注意力机制（无需循环或卷积结构）来捕捉输入序列中的全局依赖关系，从而实现高效的并行计算和更强的长距离依赖建模。

## 9.序列到序列模型（Seq2Seq）

用于**将一个序列转换为另一个序列的任务**。这种模型的核心思想是接受一个**长度可变的输入序列**，生成一个**长度可变的输出序列**。

Seq2Seq模型属于**编码器-解码器(Encoder-Decoder)**架构：

**编码器**(Encoder)：通常使用RNN(如LSTM或GRU)处理输入序列，逐步将序列信息压缩到隐藏状态中，最终生成代表整个输入序列的上下文向量。（可改进为Transformer架构）

**解码器**(Decoder)：从上下文向量开始，逐步生成输出序列的每个元素，直到产生结束标记。

### 应用

1.**机器翻译**

2.**文本摘要**

| 摘要类型   | 特点               | Seq2Seq适用性 |
| :--------- | :----------------- | :------------ |
| 抽取式摘要 | 从原文选取重要句子 | 不适用        |
| 生成式摘要 | 生成新的概括性文本 | 非常适合      |

3.**对话生成**

| 对话类型   | 特点         | Seq2Seq适用性 |
| :--------- | :----------- | :------------ |
| 任务型对话 | 完成特定任务 | 有限适用      |
| 闲聊型对话 | 开放领域交流 | 非常适合      |

## 10.预训练模型

### 1）基本概念

通过在大规模文本数据上进行预先训练，学习通用的语言表示能力，然后可以针对特定任务进行微调（Fine-tuning）。

#### **与传统方法的对比**

| 特征     | 传统NLP模型      | 预训练模型       |
| :------- | :--------------- | :--------------- |

| 训练方式 | 从零开始训练     | 预训练+微调      |
| 泛化能力 | 任务特定         | 跨任务通用       |
| 开发效率 | 低               | 高               |

1.词向量嵌入时代（Word2Vec、GloVe、FastText）（2013-2017）

2.上下文感知时代（ELMo、ULMFiT）（2018-2019）

3.Transformer时代（BERT、GPT、T5）（2019至今）

使用Transformer Dncoder，单向上下文（从左到右），擅长**文本生成**，代表模型：GPT-3、GPT-4

3. **Encoder-Decoder架构**

适合序列到序列任务，代表模型：T5、BART

# 六、序列推荐

#### **什么是 One-Hot 编码？**

One-Hot 编码是一种将**类别型数据**（如项目ID，或者在其他任务中的颜色、种类等）转换为**数值型向量**的方法。这种转换方式有以下特点：

- **唯一的“1”：** 对于每一个类别，One-Hot 编码会创建一个与总类别数量相同长度的向量。在这个向量中，只有一个位置是“1”，其余所有位置都是“0”。这个“1”的位置就代表了该类别。
- **示例：** 假设我们的推荐系统中总共有 5 个不同的项目：`Item 1, Item 2, Item 3, Item 4, Item 5`。 如果 `Item 3` 是一个会话的真实标签，那么它的 One-Hot 编码将是： `y = [0, 0, 1, 0, 0]`
